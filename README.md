# 🔋 Şarj Bitmeyen Telefon Simülatörü

## 📚 Projenin Amacı

Bu proje, insanlığın en büyük problemlerinden biri olan "telefon şarjının bitmesi" fenomenini bilimsel yöntemlerle inceleyen devrim niteliğinde bir simülasyondur. 

Telefon şarjı asla bitmez. Bitmemelidir. Bu simülatör, sonsuz şarj döngüsünü modelleyerek, kullanıcılara umut aşılar.

## 🚀 Nasıl Çalıştırılır

```bash
python sarj_simulatoru.py
```

Program çalıştığında, şarj yüzdesi yavaş yavaş azalır ama asla sıfıra inmez. Her seferinde komik bahaneler üretir.

## 📊 Özellikler

- Sonsuz döngü (gerçekten sonsuz)
- Türkçe bahaneler
- Aşırı ciddi bilimsel yaklaşım
- Hiçbir işe yaramaz ama eğlenceli

## ⚠️ Uyarı

Bu yazılım, gerçek telefonların şarjını etkilemez. Sadece simülasyon yapar. Lütfen gerçek hayatta da şarj etmeyi unutmayın.
